Protein Coffee Crush Tracker, installable version

This is a tiny Progressive Web App, or PWA. It can work like an Android app after you host it online.

Best Android setup:
1. Upload the contents of this folder to a simple static host, for example Netlify Drop, GitHub Pages, or any web host.
2. Open the hosted URL in Chrome on Android.
3. Tap the three-dot menu.
4. Tap "Add to Home screen" or "Install app."
5. Use it from your home screen.

Important:
- Opening index.html directly from your phone files may work, but it will not be as stable as hosting it.
- Your drink data is stored on that device/browser.
- Use "Backup data" occasionally. This exports a JSON file you can import later.
- Use "Export CSV" if you want a spreadsheet-style backup.
